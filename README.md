# VOLTIX Admin Portal
Vite + React 19 + TypeScript + Tailwind CSS admin management dashboard.

## Development
```bash
npm install
npm run dev
```
Runs at `http://localhost:5174/` and proxies `/api` requests to backend on port 5000.
